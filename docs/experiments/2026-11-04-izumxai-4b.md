# IzumxAI 4B: более сильная база + решатель — 4 ноября 2026

## Итог

`izumxai:4b-think` — Qwen3-4B (официальная `qwen3:4b` из Ollama, Q4_K_M, 2,5 ГБ)
с системным промптом IzumxAI, режимом рассуждений и тем же решателем
`izumxai/eval/solve.py`. Модель целиком помещается в 6 ГБ RTX 4050 Laptop,
скорость ≈53 токена/с.

### HumanEval, 164 задачи (рассуждения + самопроверка, до 3 попыток)

| Модель | Решено |
|---|---:|
| Прежний IzumxAI (`izumxai:2b`) | 79 (48,2%) |
| Базовая Qwen3-1.7B, один ответ | 90 (54,9%) |
| `izumxai:2b-think` + решатель | 111–116 (67,7–70,7%) |
| **`izumxai:4b-think` + решатель** | **141 (86,0%)** |

120 задач решены с первой попытки, 21 исправлена после ошибки на примере из
условия. Только одна задача прошла открытые примеры, но не скрытые тесты (у 2B
таких было 10). Ошибок сервера нет. Время — 2 ч 43 мин (≈60 с на задачу).
Файл: `runs/solver/humaneval-4b-think-r3.json`.

Схема та же, что для 2B: это не pass@1 без проверки, модель видит запуск своего
кода на примерах из условия. Скрытые тесты `check()` запускаются один раз, на
итоговом ответе.

`izumxai:4b-think` обходит вдвое большую `qwen3:8b` в математике, логике и коде
и работает в 4 раза быстрее на этой видеокарте. В инструкциях она немного

модель пишет `2015,3,4,730`: при десятичной запятой в тексте (3,4) такой ответ
не разобрать.

## Исправление бенча инструкций

В первом прогоне 4B набрала на инструкциях 2/12. Причина — противоречие в самом
бенче: общий системный промпт требовал последней строкой «Ответ: <значение>»,
а задача — «верни только JSON» или «ровно три пункта». Модель выполняла оба
требования, и дописанная строка ломала формат. Проверка JSON к тому же жадно
захватывала и сам объект, и его копию после «Ответ:». Теперь у задач на
инструкции свой промпт (`SYSTEM_INSTR` в `izumxai/distill/tasks.py`) без
требования «Ответ:». Это меняет условия для всех моделей одинаково, поэтому раздел
перезапущен целиком на 24 одинаковых задачах. Тот же генератор строит обучающие
данные, так что противоречие ушло и оттуда.

## Изменения в коде

- `solve.py`: в режиме рассуждений решатель сам открывает `<think>`, как это
  делает шаблон Qwen3-4B (Thinking-2507). Для 1.7B поведение то же.
- `bench.py`: флаги `--think` и `--num-predict`.
- `modelfiles/izumxai-4b-think.Modelfile` лежит в репозитории (не зависит
  от локальных GGUF), `scripts/11_solver.ps1` по умолчанию собирает и замеряет 4B.

## Воспроизведение

```powershell
ollama pull qwen3:4b
ollama create izumxai:4b-think -f modelfiles/izumxai-4b-think.Modelfile
powershell -ExecutionPolicy Bypass -File scripts\11_solver.ps1
python -m izumxai.eval.bench --models izumxai:4b-think,qwen3:8b --think --num-predict 6144 --level hard
```
