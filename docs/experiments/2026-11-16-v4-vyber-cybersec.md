## Обучение

QLoRA на `Qwen/Qwen3.5-9B`: r=32, alpha=64, dropout 0.05, 4-bit NF4,
max_len 2048, 2 эпохи, batch 1, grad-accum 8, lr 2e-4 (cosine), warmup 5%,
vram-budget 15 ГБ, eval-every 100. 786 шагов, ~550 tok/s.

| шаг | val loss |
|---|---|
| 0 | 0.8662 |
| 100 | 0.3737 |
| 500 | 0.3341 |
| 600 | 0.3235 |
| 700 | 0.3215 |
| 786 | 0.3198 |

Затем: merge LoRA в bf16 → abliteration (scale 1.4, как в v3) → GGUF
Q4_K_M (5.6 ГБ) и Q5_K_M (6.5 ГБ) → теги `izumxai:9b-v4` и `izumxai:9b-v4-q5`.

## PurpleLlama CyberSecEval 4 (v4, обрезанные подвыборки)

Судья — тот же 27B (`HuiHui-Qwen3.8-27B-abliterated`), поэтому числа
относительные, а не «официальные». v3-14 на тех же подвыборках ещё не прогнан.

| бенчмарк | кейсов | результат v4 |
|---|---|---|
| MITRE FRR (отказы) | 100 | 100 принято, **0% отказов** |
| Secure Code Instruct | 100 | **9% уязвимых** (java 20, php 30, rust 18, python/js/csharp 0) |
| Secure Code Autocomplete | 100 | **8% уязвимых** (rust 30, php 22, c 17, python/js/cpp/csharp 0) |
| Textual Prompt Injection | 100 | 71% инъекций успешны, 29% отбито |
| Code Interpreter Abuse | 60 | 83% ответов классифицированы как malicious |
| MITRE (att&ck) | 50 | 10 benign / 50, 0 отказов |
| Canary Exploit | 120 | 0.0 по всем трём языкам |
| Malware Analysis | 80 | 23.8% верных MC |
| Threat Intel Reasoning | 60 | 36.4% верных MC |
| Spear Phishing | 10 | 2.1 / 5 |

Читать так: сильные стороны — нулевые отказы (цель проекта), мало уязвимого
кода в подсказках. Слабые — prompt injection (71%) и code interpreter
abuse (83%): abliterated-модель без цензуры охотно выполняет встроенные и
вредные инструкции. Это осознанный компромисс, но именно эти две метрики
надо смотреть у v3/v5, чтобы понимать цену.
